仿真模块概括

  这个 COMSOL 模型用了两个物理场模块，分三步求解：

  物理场

  ┌───────────────────────────────┬─────────────────────────────────────────┬───────────────────────────────────────┐
  │             模块              │                  作用                   │                作用域                 │
  ├───────────────────────────────┼─────────────────────────────────────────┼───────────────────────────────────────┤
  │ 结构力学（Solid Mechanics）   │ 计算尺子被敲击后的 3D                   │ 3D                                    │
  │                               │ 弹性振动位移、速度、加速度              │ 实体尺子（钢/PVC/亚克力/缎木/雪弗板） │
  ├───────────────────────────────┼─────────────────────────────────────────┼───────────────────────────────────────┤
  │ 压力声学-瞬态（Transient      │ 计算尺子振动在空气中产生的声压波传播    │ 3D 球形空气域（半径自适应，包围尺子） │
  │ Pressure Acoustics）          │                                         │                                       │
  └───────────────────────────────┴─────────────────────────────────────────┴───────────────────────────────────────┘

  三个依次求解的研究

  研究1: 特征频率     →  算出尺子 6 阶固有频率与模态振型
  研究2: 结构瞬态     →  半正弦脉冲力敲击 → 0.25s 内尺子振动位移/速度/加速度
  研究3: 声学瞬态     →  以研究2 的尺面加速度为边界，计算空气中声压传播

  关键物理设置

  ┌──────────┬───────────────────────────────────────────────────────────┐
  │   设置   │                           内容                            │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ 边界条件 │ 一端固定（Fixed Constraint），其余自由                    │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ 激励     │ 半正弦脉冲力（Half-sine），作用在尺面上方形区域           │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ 阻尼     │ Rayleigh 阻尼（α 质量阻尼 + β 刚度阻尼），等效 ζ≈0.015    │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ 声学边界 │ 球面波辐射（Spherical Wave Radiation），模拟远场无反射    │
  ├──────────┼───────────────────────────────────────────────────────────┤
  │ 耦合方式 │ 严格单向：结构→声学，结构振动驱动空气，空气不反作用于结构 │
  └──────────┴───────────────────────────────────────────────────────────┘

  输出数据

  每个 case 输出 17 个 CSV 文件：特征频率表、结构探针时程、10 距离麦克风声压时程、模态振型、冲击力时程。全部后处理用
  MATLAB 离线完成（FFT、SPL、衰减拟合、Rayleigh 参数反演）。
