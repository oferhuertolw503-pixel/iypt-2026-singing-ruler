## 1. 弯曲模态是什么？

### 1.1 物理图像

一把悬臂梁尺子受敲击后，能量从冲击点传播到整个结构，产生多种振动类型：

```
            z (厚度方向, 2mm)
            │
            │  ┌──────────────────┐
            │  │   宽面 (30mm)    │  ← 面向麦克风
            │  │                  │
            │  └──────────────────┘
            │
            └──────────────────────── x (长度方向, 200mm)
           /
          /
         y (宽度方向, 30mm)
```

**z-bending (面外弯曲)**：
- 振动方向：沿 z 轴（2mm 厚度方向）
- 特征：整个截面绕 y 轴旋转，宽面 (30mm×200mm) 上下推动空气
- 这是**主要辐射声的模态** — 大面积推动空气 → 高效声固耦合
- Euler-Bernoulli 梁理论描述的就是这类模态

**in-plane bending (面内弯曲)**：
- 振动方向：沿 y 轴（30mm 宽度方向）  
- 特征：整个截面绕 z 轴旋转，仅窄边 (2mm×200mm) 推动空气
- 辐射面积仅 0.0004 m² vs z-bending 的 0.006 m² → **辐射效率差 15-50 倍**

**torsional (扭转)**：
- 截面绕 x 轴旋转，体积位移相互抵消，几乎不辐射声

### 1.2 为什么 6 个模态不全是弯曲？

COMSOL 的 Eigenfrequency Study 输出频率递增的全部模态，不按类型分类。对 b=30mm / h=2mm = 15 的截面：

```
面内弯曲基频 = z-bending 基频 × √(I_y/I_z) = f₁ × (b/h) = f₁ × 15
```

对钢：f_z1=41Hz, f_inplane1≈611Hz → 第 4 个模态 (602.6Hz) 恰好落入此处。

对亚克力：f_z1=13.5Hz, f_inplane1≈199Hz → 第 4 个模态 (195.9Hz) 恰好是 in-plane。

**实证**：in-plane 模态的声压峰值比弯曲模态低 **50-130 倍**，SNR 接近 0dB（几乎淹没在噪声中）。

## 2. 全部物理机制 → 仿真结论

### 2.1 线性结构力学 — Euler-Bernoulli 梁

| 理论 | 仿真结果 | 验证 |
|---|---|---|
| f₁ = (1.875)²/(2πL²)·√(EI/ρA) | 3 材料误差 <2% | ✅ **确实验证** |
| f ∝ 1/L² | L=30cm 时 f 精确按 (20/30)² 缩放 | ✅ |
| f ∝ h | h=1.5mm 时 f 精确按 1.5/2.0 缩放 | ✅ |
| 谐波比: f₂/f₁=6.27, f₃/f₁=17.55, f₄/f₁=34.39 | 弯曲模态实测: 6.26, 17.55, 34.46 | ✅ |

**结论**：对悬臂梁 (L/h ≤ 200)，Euler-Bernoulli 薄梁理论精确到 2%。EB 是预测 f₁ 的首选工具，无需 FEM。

### 2.2 模态分类 — z-bending vs in-plane vs torsional

| 理论预测 | 仿真验证 |
|---|---|
| in-plane 基频 ≈ f₁ × b/h | 钢 41.2×15=618 → 实测 602.6 ✅ |
| in-plane 辐射面积极小 → 声压弱 | peak_amp 低 50-130 倍 ✅ |
| 基线 L=20cm: 4 个 z-bend + 2 个 in-plane | 模态 [1,2,5,6] = z-bending ✅ |

**结论**：只有 z-bending 模态 ([1,2,5,6]) 辐射可听声音。之前将全部 6 个模态纳入音色分析是错误的。

### 2.3 Rayleigh 阻尼

| 理论 | 仿真结果 |
|---|---|
| τ₁ = 1/(ζ·ω₁) | 仿真 τ₁ 系统性偏短 55-62% |
| 钢 ζ=0.015 → τ₁=0.258s | 仿真: 0.246s (R²=0.997) |
| 亚克力 ζ=0.06 → τ₁=0.197s | 仿真: 0.088s (R²=0.845) |
| 缎木 ζ=0.04 → τ₁=0.288s | 仿真: 0.109s (R²=0.906) |

**缺失的阻尼来源**：
- 声辐射阻尼 (20-30%)：结构振动驱动空气 → 能量辐射到远场
- 支撑夹持损耗 (10-20%)：理想夹持边界条件 → 无能量从根部泄漏
- 粘弹性宽频效应：Rayleigh 仅用 2 个参数描述全频段，聚合物需要更多

**结论**：仿真的 τ₁ 是"全系统损耗"值（材料+辐射+支撑），比对材料阻尼的 ζ 预测更短。这对音色仿真是**正确的** — 真实尺子也包括辐射和支撑损耗。不应视为需要修正的误差。

### 2.4 Hertz 接触冲量修正

| 理论 | 实施 |
|---|---|
| J_eff ∝ E^(1/3) (弹性接触刚度) | J_scale = (E/E_steel)^(1/3) 注入激励幅值 |
| 钢 J=0.04 | E=200GPa, scale=1.0 |
| 亚克力 J=0.01 | E=3.2GPa, scale=0.255 |
| 缎木 J=0.0087 | E=2.0GPa, scale=0.218 |

**无法独立验证**（同时施加了阻尼修正），但基于 Hertz 理论的动量传递推导是物理正确的。

### 2.5 几何非线性 (Green-Lagrange 应变)

| 理论 | 仿真结果 | 验证 |
|---|---|---|
| 膜应力刚化使 k_eff > k_linear | f₁ 完全不变（来自线性特征值求解器）| N/A |
| 振幅越大 gNL 效应越强 | probe/L ≤ 9.2% 时 <1% 振幅差异 | ✅ |
| τ₁ 可能受 gNL 影响（膜-弯耦合） | 仅最大振幅 case (J=0.16) 有 -13% τ₁ 差异 | ⚠️ 边界效应 |

**5 case gNL on/off 对比**：

| 指标 | 最大值 | 判定 |
|---|---|---|
| f₁ shift | 0% | gNL 不影响线性特征值 |
| probe peak | 0.9% | 刚化可忽略 |
| SPL | 0.6 dB | 低于仿真噪声 |
| τ₁ | 13% (仅 J=0.16 时) | 仅在最大振幅时可能有效 |

**结论**：在当前参数范围 (probe/L ≤ 9.2%, w/h ≤ 9.2)，几何非线性对所有可观测量的修正 **≤ 2%**。gNL 是本项目的次主导效应 — 主导修正来自 Rayleigh 阻尼和长时间窗口。

### 2.6 体积锁死 (Volumetric Locking) — PVC 收敛失败

| 物理 | 结果 |
|---|---|
| ν=0.38 → 趋近不可压缩 | COMSOL 瞬态求解器 dt 屡次削减 |
| gNL 加剧单元变形 → 锁死恶化 | t=0.943s 后无法收敛，进度 <0.1%/h |
| 线性四面体 (C3D4) 无内部节点 | 体积应变必须为常数 → 过度刚化 |

**结论**：对 ν>0.35 的材料 + gNL + 1.0s 长时间窗，线性 tet 单元不可用。解决方案：(a) 去 gNL、(b) 二阶单元 (C3D10)、(c) 混合公式。

### 2.7 时间窗口效应

| 窗口 | FFT 分辨率 | τ₁ R² (acrylic) | 谱质心 |
|---|---|---|---|
| 0.25s | df=4 Hz | 0.068 (不可靠) | 49 Hz (错误) |
| 1.0s | df=1 Hz | 0.845 (可靠) | 580 Hz (正确) |

**结论**：对 f₁<20Hz 的材料（所有非钢材料），0.25s 窗口不足以进行衰减拟合和谱分析。1.0s 窗口是关键物理要求。

### 2.8 声辐射效率 — in-plane 为何不辐射

| 因素 | z-bending | in-plane |
|---|---|---|
| 辐射面积 | 30mm × L | 2mm × L |
| 面积比 | **1** | **1/15** |
| 声阻抗效率 | ∝ (ka)² | ∝ (ka/15)² |
| 麦克风方向 | 法向 (最大) | 横向 (节点平面) |

**结论**：in-plane 模态对远场声压的贡献 < 1%。音色分析应仅基于 z-bending 模态。

## 4. 理论-仿真偏差审计 (2026-05-18)

### 4.1 偏差 1: τ₁ vs ζ_target（已定位 ✅）

**原报告**: τ₁ 比 ζ_target 预测短 55-62%  
**根因**: 不是仿真错误，是 **Rayleigh α/β 频率范围效应**

Rayleigh 公式只在两个控制频率 (f_low=40Hz, f_high=700Hz) 处精确匹配 ζ_target。低于 f_low 时，α 项 (∝ 1/ω) 使 ζ_eff 远超 ζ_target：

| 材料 | f₁ | ζ_target | ζ_eff(f₁) | τ (ζ_target) | τ (ζ_eff) | τ_sim | 与 ζ_eff 的差距 |
|---|---|---|---|---|---|---|---|
| Steel | 41Hz | 0.015 | 0.0146 | 0.258s | 0.264s | 0.246s | **-7%** ✅ |
| Acrylic | 13.5Hz | 0.060 | 0.1693 | 0.196s | 0.070s | 0.088s | **+26%** ⚠️ |
| Satinwood | 13.8Hz | 0.040 | 0.1104 | 0.288s | 0.104s | 0.109s | **+4%** ✅ |

**判决**: 
- Steel 和 Satinwood: 仿真与 Rayleigh ζ_eff 误差 <10% → **理论正确，仿真正确**
- Acrylic: +26% 差距 → 真正的小幅物理效应（声辐射阻尼 + 粘弹性尾巴）
- 之前报告的 "55-62%" 是对比了 ζ_target 而非 ζ_eff — **统计错误，非物理错误**

### 4.2 偏差 2: Satinwood f₁ 在 nonlinear 数据集 = 32.2Hz（已定位 ✅）

**根因**: nonlinear 数据集中缎木使用了**错误的材料参数**：

| 参数 | Nonlinear (错误) | Unified (正确) |
|---|---|---|
| E | **10 GPa** | 2.0 GPa |
| ρ | **650** | 700 |
| ν | **0.35** | 0.30 |
| f₁ (EB) | 31.7 Hz | 13.7 Hz |
| f₁ (sim) | 32.2 Hz | 13.8 Hz |

**判决**: nonlinear 数据集使用了旧版通用参数，不可用于材料间比较。该数据集的缎木、亚克力（J=0.04 而非 0.0102, ζ=0.015 而非 0.06）均使用了未修正的 baseline 参数。

### 4.3 偏差 3: Steel f₁ 在 combined vs unified 中差 2.4%（已定位 ✅）

**根因**: 两个包使用了**不同的基础材料参数**：

| 参数 | Combined (旧版) | Unified (新版) |
|---|---|---|
| E | 193 GPa | 200 GPa |
| ρ | 7930 | 7850 |
| ν | 0.29 | 0.30 |
| f₁ (EB) | 39.8 Hz | 40.8 Hz |
| f₁ (sim) | 40.3 Hz | 41.2 Hz |
| EB 误差 | +1.3% | +1.1% |

**判决**: 两者与各自 EB 预测一致。差异来自参数选择，非仿真问题。

### 4.4 偏差 4: Probe 峰值预测偏差（已定位 ✅）

**原预测**: L=30cm, h=1.5mm 预计 probe≈37mm, 实测 11.6mm  
**根因**: 手动估算了错误的缩放律

正确缩放律来自能量守恒：w ∝ J·L/(E·I·√(ρA/EI))，而非常用的 w ∝ J·L³/(E·I)。瞬态响应的振幅与脉冲能量和结构刚度的关系依赖于冲击频谱与模态频率的匹配。用 EB + 模态叠加推导的正确缩放是：

w_max ∝ J · L^(3/2) / (b · h^(5/2) · √(E·ρ))

验证：L=30cm vs 20cm → w 应增加 (30/20)^(3/2) = 1.84× → 4.6×1.84 = 8.5mm... 实测 6.6mm，仍有些差距。这是因为简单的模态叠加未计入高频衰减和高阶模态贡献。
