# 尺子振动发声的音调、响度与音色：仿真分析学术演讲报告

> 数据根目录：`outputs/requested_timbre_complete_enhanced_medium/`
> 推荐用途：学术演讲、竞赛答辩、论文结果讲解、后续写作 agent 读取。
> 核心口径：本文中的“音色”均指“仿真频谱音色代理指标”，不直接等同于人耳主观听感全貌。

## 1. 演讲开场与核心问题

各位老师、同学好。本研究关注一个日常但具有明确声-结构耦合特征的现象：尺子伸出桌边后被敲击，会先发生结构振动，再通过空气辐射形成可听声。

这个现象看似简单，但里面至少包含三个层次的问题：

| 层次 | 问题 | 对应输出 |
|---|---|---|
| 音调 | 尺子主要发出哪个频率的声音？ | `f_dom_refined_hz`、`second_peak_freq_hz` |
| 响度 | 这个声音在麦克风位置有多强？ | `spl_rms_db`、`p_rms_pa`、`p_peak_pa` |
| 音色 | 除了主频和响度外，声音的频谱分布和衰减过程有什么差异？ | `spectral_centroid_hz`、`spectral_flatness`、能量比例、`q_estimate`、衰减时间 |

本报告的核心问题是：

> 当尺子的材料发生变化时，声学输出的音调、响度和仿真频谱音色代理指标会如何变化？这些变化是否可以由结构振动、声学辐射和阻尼衰减共同解释？

为了回答这个问题，我们使用增强 medium 仿真数据作为唯一主数据源，并明确区分哪些结果可以作为强结论，哪些只能作为诊断性观察。

## 2. 物理现象：尺子为什么会振动发声

尺子振动发声可以理解为一个连续的能量传递过程：

```text
冲量输入 -> 尺子弯曲模态响应 -> 表面速度扰动空气 -> 麦克风声压时程 -> 频谱/时频/衰减指标
```

更具体地说：

1. 敲击给尺子一个短时冲量 `J_Ns`。
2. 尺子发生弯曲振动，不同模态具有不同固有频率和振型。
3. 尺子表面运动推动周围空气，形成压力波。
4. 麦克风位置记录声压时程 `p(t)`。
5. MATLAB 对声压时程做高精度频谱和衰减后处理，得到音调、响度和音色代理指标。

这个过程有两个重要特点：

| 特点 | 物理含义 | 对结果的影响 |
|---|---|---|
| 多模态 | 尺子不是只按一个频率振动，而是可能同时包含多阶弯曲模态 | 声压频谱可能出现多个峰 |
| 阻尼衰减 | 不同频率、不同材料的能量耗散速度不同 | 声音持续时间和频谱随时间变化 |

因此，单独看主频是不够的。一个材料的发声特征至少要同时看频率位置、声压强度、频谱复杂度和时间衰减。

## 3. 研究目标：音调、响度、音色分别对应什么

在这份报告中，我们不把“声音好不好听”作为直接结论，因为那需要听感实验和心理声学模型。我们做的是更可控的仿真问题：

| 声学概念 | 本项目中的仿真代理 | 解释方式 |
|---|---|---|
| 音调 | 声压频谱主峰 `f_dom_refined_hz` | 主峰越稳定、主峰/次峰比越大，音调越清晰 |
| 响度 | 麦克风点 `spl_rms_db` | SPL 越高，仿真测点声压越强 |
| 音色：频率分布 | 频谱质心、平坦度、rolloff、低/中/高频能量比例、谱峰数量 | 描述声音能量集中在低频还是扩展到高频 |
| 音色：时间分布 | Q 因子、对数衰减、50% 衰减时间、85% 能量释放时间 | 描述声音是快速消失还是持续拖尾 |

所以本文的“音色”不是一个单一数值，而是一组频域和时域指标共同构成的画像。这个处理方式更适合仿真研究，因为它能把材料差异拆解成可计算、可复核的物理量。

## 4. 仿真体系：结构、声场、激励、材料与后处理

本报告只使用增强 medium 音色仿真数据：

| 项目 | 数值 |
|---|---|
| 数据根目录 | `outputs/requested_timbre_complete_enhanced_medium/` |
| 材料 | Steel, Acrylic, PVC, Satinwood, Xuefu board |
| 冲量水平 | `J_low = 0.004 N·s`, `J_orig = 0.04 N·s` |
| 主结论数据 | `J_low = 0.004 N·s` |
| 诊断对照数据 | `J_orig = 0.04 N·s` |
| 时间窗 | `0.75 s` |
| 时间步 | `1e-4 s` |
| 网格控制 | `100 elem` |
| 模态点数 | `241` |
| 低频模态搜索 | `eigen_shift = 20 Hz` |
| 后处理方法 | Hann 窗、4 倍补零、单边幅值谱、三点对数抛物线峰值精化 |

这里有一个关键选择：主结论只使用 `J_low`。原因是低冲量更接近小挠度线性响应，适合比较材料本身对声学输出的影响。`J_orig` 放大了 10 倍冲量，主要用于检查冲量敏感性和线性风险，不用于材料主结论。

## 5. 线性/非线性边界：相对于小挠度线性声-结构模型

本项目中的 `linear` 和 `nonlinear_risk` 不是绝对标签。它们相对于当前采用的小挠度线性声-结构解释框架。

换句话说，我们问的是：

> 这个 case 的结构振幅是否还足够小，使得它可以用线性模态、线性声学辐射和近似比例响应来解释？

当前使用结构探针峰值与自由长度的比值作为工程判据：

| 判据 | 状态 | 学术解释 | 论文使用方式 |
|---|---|---|---|
| `probe_peak/L <= 0.05` | `linear` | 小挠度近似可信 | 可作为主结论 |
| `0.05 < probe_peak/L <= 0.10` | `borderline` | 接近边界，应谨慎 | 只用于趋势或诊断 |
| `probe_peak/L > 0.10` | `nonlinear_risk` | 振幅过大，线性解释风险高 | 不用于强结论 |

需要特别强调：`nonlinear_risk` 不表示我们已经证明材料进入复杂本构行为，也不表示模型发生真实破坏。它的含义更克制：该仿真结果的结构振幅已经太大，不适合继续用小挠度线性模型给出强材料规律。

冲量敏感性也能帮助理解这个边界。若系统处于理想线性区，冲量放大 10 倍，声压幅值约放大 10 倍，对应 SPL 增加约 `20 dB`，而主频应基本不变。但如果结构振幅同时变得很大，即使 SPL 缩放看起来合理，仍然不能把该 case 当作可靠的线性材料对比。

## 6. 物理量意义总表

### 6.1 激励量

| 字段 | 单位 | 人话解释 | 物理含义 | 本项目用途 | 表述注意 |
|---|---:|---|---|---|---|
| `J_Ns` | N·s | 敲击“有多猛” | 力对时间的积分，即冲量 | 区分 `J_low` 和 `J_orig` | 主结论只用 `J_low` |
| `force_z_N` | N | 某一时刻的敲击力 | z 向瞬态载荷 | 追溯激励时程 | 不单独代表总输入能量 |
| `impact_force_timeseries.csv` | s, N | 敲击过程记录 | 载荷-时间曲线 | 保证 case 可追溯 | 缺失时应在 summary 标注 |

### 6.2 结构量

| 字段 | 单位 | 人话解释 | 物理含义 | 本项目用途 | 表述注意 |
|---|---:|---|---|---|---|
| `freq_hz` | Hz | 尺子“自己喜欢振”的频率 | 结构固有频率 | 模态-声学匹配 | 与声压主峰不必完全相等 |
| `mode` | 无量纲 | 第几阶振动形态 | 模态编号 | 组织模态结果 | 不是时间序号 |
| `mode_shapes` | 归一化或 m | 尺子哪里弯得多 | 模态振型 | 解释结构响应空间分布 | 通常比较形状而非绝对幅值 |
| `probe_peak_m` | m | 探针处最大振幅 | 局部结构峰值响应 | 判断振幅大小 | 不等同于 tip 振幅 |

| `probe_peak/L` | 无量纲 | 振幅占自由长度比例 | 小挠度可用性代理 | 线性风险判据 | 这是解释边界，不是材料性质 |

## 7. 音调结果：主频、次峰、主峰清晰度

低冲量主数据的音调结果如下：

| 材料 | `f_dom_refined_hz` | 次峰频率 | 主峰/次峰比 | 音调解释 |
|---|---:|---:|---:|---|
| Steel | 39.7 Hz | 205.1 Hz | 32.84 | 主音最清晰，主峰突出 |
| Acrylic | 13.5 Hz | 227.1 Hz | 6.49 | 低主频，但副峰参与明显 |
| PVC | 12.1 Hz | 205.1 Hz | 5.01 | 低主频，频谱峰更多 |
| Satinwood | 32.1 Hz | 185.5 Hz | 10.47 | 主音清晰，频谱集中 |
| Xuefu board | 8.2 Hz | 51.3 Hz | 1.10 | 主峰优势弱，仅作诊断 |

演讲时可以这样解释：

> 从音调角度看，Steel 的主峰并不是最高 SPL，但它的主峰/次峰比最高，因此它的主音最清晰。Satinwood 的主音也较清楚。Acrylic 和 PVC 虽然主频更低，但副峰和宽频成分明显参与，因此它们不是单一低频声。Xuefu board 的主峰优势很弱，并且线性风险较高，所以不把它作为强音调规律。

这里的关键是区分“主频低”和“音调清晰”。主频低只说明最大声压峰的位置低；音调是否清晰，还要看主峰是否明显高于次峰，以及频谱是否被大量副峰填满。

## 8. 响度结果：SPL 与冲量敏感性

低冲量主数据下，SPL 排序如下：

| 排名 | 材料 | `spl_rms_db` | 说明 |
|---:|---|---:|---|
| 1 | Xuefu board | 88.2 dB | 声压最高，但线性风险高 |
| 2 | Satinwood | 82.8 dB | 四个线性主材料中最高 |
| 3 | Acrylic | 81.0 dB | 与 PVC 接近 |
| 4 | PVC | 80.7 dB | 与 Acrylic 接近 |
| 5 | Steel | 62.0 dB | 声压最低，但主音最清晰 |

如果只看可作为主结论的四个线性材料，则 Satinwood 的 SPL 最高，Acrylic 和 PVC 接近，Steel 最低。

这说明响度与音调清晰度不是同一个概念。Steel 的主峰非常突出，但声压级最低；Satinwood 兼具较高 SPL 和低频集中频谱；PVC 的声压较高且频谱更宽，但主峰清晰度不如 Steel。

冲量敏感性方面，`J_orig = 0.04 N·s` 相比 `J_low = 0.004 N·s` 放大 10 倍。仿真结果中 SPL 增益约为 `19.5-20.0 dB`，符合线性声压幅值缩放的基本预期：

| 材料 | SPL 增益 | 主频偏移 | `J_low` 状态 | `J_orig` 状态 |
|---|---:|---:|---|---|
| Steel | 20.0 dB | 0.3 Hz | linear | linear |
| Acrylic | 19.5 dB | 0.0 Hz | linear | nonlinear_risk |
| PVC | 19.6 dB | 0.0 Hz | linear | nonlinear_risk |
| Satinwood | 20.0 dB | 0.1 Hz | linear | nonlinear_risk |
| Xuefu board | 19.7 dB | 267.9 Hz | nonlinear_risk | nonlinear_risk |

这里的结论要谨慎：SPL 缩放接近 20 dB 并不自动说明所有 case 都可作为线性主数据。因为 Acrylic、PVC、Satinwood 和 Xuefu board 在原始冲量下结构振幅过大，已经超出小挠度解释边界。

## 9. 音色频率分布：质心、平坦度、能量比例、谱峰数量

音色的频率分布结果如下：

| 材料 | 频谱质心 | 平坦度 | 低频能量 | 中频能量 | 高频能量 | 谱峰数量 |
|---|---:|---:|---:|---:|---:|---:|
| Steel | 67.4 Hz | 0.0066 | 98.25% | 1.29% | 0.46% | 24 |
| Acrylic | 140.2 Hz | 0.0161 | 85.88% | 8.35% | 5.77% | 75 |
| PVC | 235.0 Hz | 0.0255 | 73.04% | 17.27% | 9.69% | 300 |
| Satinwood | 62.1 Hz | 0.0053 | 98.89% | 0.63% | 0.48% | 2 |
| Xuefu board | 800.3 Hz | 0.0615 | 77.86% | 2.11% | 20.02% | 702 |

从频率分布看，材料可以分成三类：

| 类别 | 材料 | 特征 |
|---|---|---|
| 低频离散谱峰型 | Steel, Satinwood | 低频能量超过 98%，平坦度低，主峰或少数峰主导 |
| 低主频但宽频参与型 | Acrylic, PVC | 主频低，但频谱质心和中高频能量更高 |
| 复杂宽带诊断型 | Xuefu board | 质心和平坦度最高，但线性风险高 |

演讲时可以强调：

> 频谱质心告诉我们声音能量的重心在哪里。Steel 和 Satinwood 的质心只有 67.4 Hz 和 62.1 Hz，说明能量高度集中在低频。PVC 的主频虽然只有 12.1 Hz，但质心达到 235.0 Hz，说明它并不是单纯低频声，而是有更多中高频成分参与。Xuefu board 的质心达到 800.3 Hz，但由于线性风险高，只作为复杂响应案例。

平坦度的解释也很重要。平坦度低表示频谱更像几个突出的尖峰；平坦度高表示频谱更宽、更复杂。Satinwood 的平坦度最低，谱峰数量也最少，说明它的频谱最集中。PVC 的平坦度和谱峰数量更高，说明它的声学输出更复杂。

## 10. 音色时间分布：Q 因子、对数衰减、能量持续时间

音色还包括声音如何随时间消失。当前时域指标如下：

| 材料 | Q 因子 | 对数衰减 | 50% 衰减时间 | 85% 能量时间 | 时间特征 |
|---|---:|---:|---:|---:|---|
| Steel | 67.9 | 0.0463 | 0.0101 s | 0.1366 s | 衰减慢，振动保持时间长 |
| Acrylic | 29.6 | 0.1061 | 0.0307 s | 0.0444 s | Q 低，主要能量释放快 |
| PVC | 28.6 | 0.1098 | 0.0322 s | 0.0471 s | Q 低，频谱宽但持续短 |
| Satinwood | 55.1 | 0.0570 | 0.0119 s | 0.1337 s | 衰减慢，接近 Steel |
| Xuefu board | 31.1 | 0.1009 | 0.0487 s | 0.0861 s | 中等持续，线性风险较高 |

Q 因子可以理解为振动“保留能量”的能力。Q 越高，衰减越慢；对数衰减越大，衰减越快。根据结果，Steel 和 Satinwood 的 Q 明显高于 Acrylic 和 PVC，说明前两者的振动更持久。

需要注意，`decay_time_50pct_s` 和 `energy_decay_85pct_s` 不是同一个概念。前者看的是包络或能量降到一半的时间，后者看的是主要能量释放完成的时间。对于多模态信号，两个指标不一定严格同序。因此报告中更适合把它们共同解释为“时间音色画像”，而不是只挑一个绝对排序。

## 11. 材料对比画像

### 11.1 Steel

Steel 的主频为 `39.7 Hz`，SPL 为 `62.0 dB`，低频能量比例为 `98.25%`，主峰/次峰比为 `32.84`，Q 因子为 `67.9`。

它的特征是低响度、主音最清晰、低频集中、衰减较慢。Steel 很适合作为“清晰低频主音”的代表材料。

### 11.2 Satinwood

Satinwood 的主频为 `32.1 Hz`，SPL 为 `82.8 dB`，低频能量比例达到 `98.89%`，频谱平坦度为 `0.0053`，Q 因子为 `55.1`。

它的特征是较高响度、频谱最集中、低频主导、衰减较慢。与 Steel 相比，Satinwood 的主峰清晰度略低，但 SPL 更高。

### 11.3 Acrylic

Acrylic 的主频为 `13.5 Hz`，SPL 为 `81.0 dB`，频谱质心为 `140.2 Hz`，高频能量比例为 `5.77%`，Q 因子为 `29.6`。

它的特征是低主频但中高频参与增强。Acrylic 不能简单描述成“更低的音”，因为它的主峰低，但频谱能量已经明显扩展到更高频段。

### 11.4 PVC

PVC 的主频为 `12.1 Hz`，SPL 为 `80.7 dB`，频谱质心为 `235.0 Hz`，高频能量比例为 `9.69%`，谱峰数量为 `300`。

它是四个线性主材料中频谱最宽、高频比例最高、谱峰最复杂的材料。因此 PVC 可以作为“宽频复杂音色代理”的代表。

### 11.5 Xuefu board

Xuefu board 的主频为 `8.2 Hz`，SPL 为 `88.2 dB`，频谱质心为 `800.3 Hz`，高频能量比例为 `20.02%`，谱峰数量为 `702`。

如果只看声学指标，它似乎是最复杂、最高频参与最强的材料。但它的 `probe_peak/L = 0.119`，超过线性风险阈值。因此本报告不把 Xuefu board 写成强材料规律，而是作为“低冲量下仍可能诱发复杂宽带响应”的诊断案例。

## 12. 可靠性与边界：哪些结论强，哪些只能诊断

为了让演讲和论文表述更稳健，结论需要分层：

| 结论 | 数据依据 | 强度 |
|---|---|---|
| Steel 与 Satinwood 呈低频离散谱峰主导 | `J_low`，线性状态，低频能量超过 98% | strong |
| Acrylic 与 PVC 具有更明显的中高频参与 | `J_low`，线性状态，质心和高频比例高于 Steel/Satinwood | strong |
| PVC 是四个线性材料中频谱最宽者 | `J_low`，线性状态，峰数 300，高频比例 9.69% | strong |
| Satinwood 兼具较高 SPL 与低频集中 | `J_low`，线性状态，SPL 82.8 dB，低频 98.89% | strong |
| Xuefu board 的频谱最复杂 | `J_low`，但 `nonlinear_risk` | diagnostic |
| `J_orig` 下柔性材料振幅过大 | 冲量敏感性表 | diagnostic |

不能过度表述的内容：

| 不建议写法 | 更稳健写法 |
|---|---|
| “仿真证明了真实听感音色” | “仿真给出了频谱和衰减意义上的音色代理指标” |
| “Xuefu board 是最高频音色材料” | “Xuefu board 出现复杂宽带响应，但线性风险较高” |
| “所有原始冲量结果都可用于材料比较” | “原始冲量只用于诊断冲量放大后的线性风险” |
| “SPL 越高音调越清晰” | “响度、主峰清晰度和频谱复杂度是不同维度” |

这部分是答辩中最重要的防线：我们不是把所有结果都当成同等可靠，而是主动把强结论和诊断结论分开。

## 14. 最终结论与答辩问答准备

### 14.1 最终结论

本研究通过增强 medium 声-结构仿真和 MATLAB 高精度后处理，对尺子振动发声的音调、响度和仿真频谱音色代理指标进行了系统分析。

主要结论是：

| 编号 | 结论 |
|---|---|
| C1 | Steel 和 Satinwood 的声学输出由低频离散谱峰主导，频谱质心低、平坦度低、低频能量比例超过 98%。 |
| C2 | Acrylic 和 PVC 虽然主频较低，但中高频成分更明显，表现为更高频谱质心、更高平坦度和更多谱峰。 |
| C3 | PVC 是四个线性主材料中频谱最宽、高频参与最多的材料。 |
| C4 | Satinwood 在四个线性主材料中 SPL 最高，并保持低频集中和较高 Q 因子。 |
| C5 | Steel 的 SPL 最低，但主峰/次峰比最高，因此主音最清晰。 |
| C6 | Xuefu board 的频谱复杂度最高，但由于 `nonlinear_risk`，只能作为诊断性材料案例。 |
| C7 | `J_low` 是材料主结论数据源；`J_orig` 只用于冲量敏感性和线性风险诊断。 |

一句话总结：

> 材料不仅改变尺子发声的主频，也改变频谱能量分布和时间衰减特征；因此，尺子发声的“音色”应通过频域和时域代理指标共同描述，而不是只看主频或 SPL。

### 14.2 可能被问到的问题

| 问题 | 推荐回答 |
|---|---|
| 这里的音色是不是人耳听到的音色？ | 不是完整听感结论。这里是仿真频谱音色代理指标，包括频谱质心、平坦度、能量比例、谱峰数量和衰减指标。 |
| 为什么不用 `J_orig` 做主结论？ | 因为除 Steel 外，其他材料在 `J_orig` 下结构振幅超过小挠度线性解释边界。为了比较材料本身影响，主结论使用更稳健的 `J_low`。 |
| `nonlinear_risk` 是不是说明材料坏了？ | 不是。它只表示该 case 不适合继续用小挠度线性模型强解释，不代表材料损伤。 |
| 为什么 Steel SPL 低但说主音清晰？ | SPL 表示声压强度，主音清晰度看主峰/次峰比和频谱集中程度。Steel 的主峰/次峰比最高，所以主音最清楚。 |
| 为什么 PVC 主频低但说高频参与更多？ | 主频只是最大峰位置；频谱质心和能量比例显示 PVC 有更多中高频能量，因此频谱更宽。 |
| Xuefu board 能不能作为结论？ | 可以作为诊断性现象，不能作为强材料规律。它的频谱复杂，但结构振幅超过线性风险阈值。 |

### 14.3 后续工作

如果要把本研究进一步推进到更高可信度，建议优先做三件事：

1. 对 Xuefu board 继续降低冲量，寻找满足 `probe_peak/L <= 0.05` 的线性可用 case。
2. 增加多麦克风测点或声功率指标，减少单一测点 SPL 对空间位置的依赖。
3. 引入 A-weighting、Bark/Mel 频带或实验录音，对仿真频谱音色代理指标和人耳听感建立联系。

## 15. 演讲收束句

本研究的价值在于，它把一个日常的尺子发声现象拆解成了可计算的声-结构耦合问题。通过区分音调、响度和仿真频谱音色代理指标，我们能够看到：材料并不是简单地让声音“高一点”或“响一点”，而是同时改变了主峰位置、频谱宽度、能量分布和振动衰减过程。

因此，尺子的声音不是一个单一频率，而是结构模态、材料阻尼、声学辐射和激励幅值共同形成的动态频谱结果。
