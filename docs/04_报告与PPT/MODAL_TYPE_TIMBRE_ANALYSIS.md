# Modal Type Identification & Corrected Timbre Analysis

> 2026-05-18 | 基于 COMSOL 3D 实体解 + Euler-Bernoulli 理论验证

## 1. 核心发现：6 个模态 ≠ 6 个弯曲模态

COMSOL 3D Solid Mechanics 输出前 6 阶频率，但**不按模态类型分组**。对于宽扁矩形截面的悬臂梁 (b=30mm, h=2mm, b/h=15)，模态类型包含：

| 模态类型 | 振动方向 | 辐射面积 | 声耦合效率 |
|---|---|---|---|
| **z-bending** (面外弯曲) | z 方向（2mm 厚度方向）| b×L = 0.006m² | **高** — 面向麦克风 |
| **in-plane bending** (面内弯曲) | y 方向（30mm 宽度方向）| h×L = 0.0004m² | **极低** — 辐射面窄 15 倍 |
| **torsional** (扭转) | 绕 x 轴 | 极小 | **几乎为零** — 体积位移抵消 |

## 2. Euler-Bernoulli 悬臂梁谐波系列

面外弯曲 (z-direction):
```
β_n L = [1.875, 4.694, 7.855, 10.996, 14.137, 17.279]
f_n / f_1 = (β_n L / β_1 L)² = [1.000, 6.267, 17.548, 34.386, 56.843, 84.986]
```

面内弯曲 (y-direction):
```
f_inplane1 / f_z1 = √(I_y / I_z) = b/h = 15.0
```

即面内基频 = z-bending 基频的 15 倍。

## 4. 对音色分析的修正

### 4.1 修正前（错误）

之前将全部 6 个模态当作弯曲模态，计算 τ₁~τ₆ 和 Q₁~Q₆。这导致：
- τ₃ 和 τ₄ 描述了 in-plane/mixed 模态的衰减 → **与辐射声无关**
- Q₃, Q₄ 包含 in-plane 的耗散机制 → **不反映声学阻尼**
- 音色结论掺杂了非声学模态的信息

### 4.2 修正后

仅弯曲模态 (z-bending) 的衰减和 Q 值与辐射声相关：

| 材料 | 弯曲模态 | f₁ (声) | f₂ (声) | f₃ (声) | f₄ (声) |
|---|---|---|---|---|---|
| Steel | 1,2,5,6 | 41.2 Hz | 258 Hz | 723 Hz | 1421 Hz |
| Acrylic | 1,2,5,6 | 13.5 Hz | 84 Hz | 236 Hz | 464 Hz |
| Satinwood | 1,2,5,6 | 13.8 Hz | 86 Hz | 242 Hz | 476 Hz |

| 材料 | 弯曲 τ₁ | 弯曲 τ₂ | 弯曲 τ₃ (mode 5) | 弯曲 τ₄ (mode 6) |
|---|---|---|---|---|
| Steel | 0.246 (R²=0.997) | 0.149 (R²=0.761) | 0.003 (R²=0.750) | 0.004 (R²=0.786) |
| Acrylic | 0.088 (R²=0.845) | 0.048 (R²=0.894) | 0.008 (R²=0.609) | 0.009 (R²=0.969) |
| Satinwood | 0.109 (R²=0.906) | 0.050 (R²=0.893) | 0.027 (R²=0.486) | 0.013 (R²=0.980) |

### 4.3 声辐射效率

辐射效率 = 声压峰值 / 结构振幅。z-bending 模态的声辐射效率远高于 in-plane：

| 材料 | bend-1 辐射 (Pa) | bend-2 (Pa) | in-plane (Pa) | 效率比 |
|---|---|---|---|---|
| Steel | 0.126 | 0.012 | 0.0015 | **80×** |
| Acrylic | 0.0048 | 0.00063 | 0.00009 | **53×** |
| Satinwood | 0.019 | 0.0044 | 0.00015 | **130×** |

钢的弯曲模态辐射效率最高 — 因为钢的高 E 产生更高频的振动，高频模态的辐射效率更高 (f↑ → 声阻抗匹配↑)。

### 4.4 频带能量（仅弯曲模态）

从 `band_decay_metrics.csv`：

**Steel**:
- 30-90 Hz (包含 f₁=41): **142361** — 主导能量
- 180-330 Hz (包含 f₂=258): **47166**

Acrylic 和 Satinwood 在低频带（包含 f₁）同样主导，高频带迅速衰减。

## 5. 对声辐射的物理理解

**为什么 in-plane 模态几乎不辐射声音？**

1. **辐射面积**: z-bending 的宽面 (30mm × 200mm) 推动空气。in-plane bending 沿窄边 (2mm × 200mm) 振动 → 有效辐射面积减少 15 倍
2. **声阻抗匹配**: kHz 级以下，小辐射面的声阻抗效率 ∝ (ka)²，其中 a 是有效半径。2mm vs 30mm 面 → 效率差 (0.002/0.03)² ≈ 0.004×
3. **方向性**: 麦克风位于 z 方向 2cm 处，in-plane 弯曲的声波向 y 方向辐射，麦克风位于节点平面
