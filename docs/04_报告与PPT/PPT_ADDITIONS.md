## Slide 14 — EB 推导：控制方程 → 基频 ➕📐

将尺子振动视作悬臂梁横向自由振动。惯性力与弹性恢复力平衡，构成 Euler-Bernoulli 方程。

```
\rho A\frac{\partial^2 w(x,t)}{\partial t^2}+EI\frac{\partial^4 w(x,t)}{\partial x^4}=0
```

设解为空间模态与简谐时间函数乘积叠加，分离变量。空间部分为四阶常微分方程。

```
w(x,t)=\sum_n\Phi_n(x)e^{i\omega_n t}
```

```
EI\frac{d^4\Phi}{dx^4}-\omega^2\rho A\Phi=0
```

通解由三角函数与双曲函数的线性组合构成。

```
\Phi(x)=C_1\cos(\beta x)+C_2\sin(\beta x)+C_3\cosh(\beta x)+C_4\sinh(\beta x)
```

悬臂梁固定端位移与转角为零，自由端弯矩与剪力为零。

```
\Phi(0)=0,\;\Phi'(0)=0,\quad\Phi''(L)=0,\;\Phi'''(L)=0
```

## Slide 15 — 基频 → 缩放律 → COMSOL 验证 ➕📐📊

通解代入边界条件得齐次方程组。系数行列式为零导出特征方程。

```
\cos(\beta L)\cosh(\beta L)+1=0
```

前四个根：β₁L=1.875, β₂L=4.694, β₃L=7.855, β₄L=10.996。由 β⁴=ρAω²/EI 解出基频。代入 I=bh³/12, A=bh，宽度 b 消去。

```
f_1=\frac{(\beta_1L)^2}{2\pi L^2}\sqrt{\frac{EI}{\rho A}}=\frac{1.875^2}{2\pi}\cdot\frac{h}{L^2}\cdot\sqrt{\frac{E}{12\rho}}
```

由此读出三条缩放律。

```
f_1\propto\frac{1}{L^2},\quad f_1\propto h,\quad f_1\propto\sqrt{\frac{E}{\rho}}
```

COMSOL 6.1 四种材料验证。E 跨 100 倍，误差 <2%。

| 材料 | E/GPa | ρ | 理论/Hz | 仿真/Hz | 误差 |
|---|---|---|---|---|---|
| Steel | 200 | 7850 | 40.8 | 41.2 | +1.1% |
| Acrylic | 3.2 | 1190 | 13.2 | 13.5 | +1.6% |
| Satinwood | 2.0 | 700 | 13.7 | 13.8 | +1.1% |
| PVC | 3.0 | 1380 | 11.9 | 12.1 | +1.9% |

📊 `fig_f1_vs_material.png` `viz_harmonic_series.png`

**实验拟合**（写 PPT 文本框）：f₁ vs 1/L²：k=16494 Hz·cm² (理论 16306)，R²=0.9913。f₁ vs h：k≈36 Hz/mm (与理论 36.2 一致)。f₁ vs √(E/ρ)：C=271 (理论 246)，偏差 +10.2%。

## Slide 17 — 音色 1：多模态叠加 ➕📐📊

尺子受敲击后同时激发多阶弯曲模态。声压为各模态贡献的叠加，每阶有其固有频率 fₙ（EB 给出）和独立衰减时间 τₙ（阻尼决定）。

```
p(t)=\sum_n A_n e^{-t/\tau_n}\sin(2\pi f_n t+\phi_n)
```

各阶初始振幅 Aₙ 取决于冲击位置与模态振型的匹配度。衰减时间 τₙ 由 Rayleigh 阻尼给出。

```
\tau_n=\frac{1}{\zeta_n\cdot 2\pi f_n},\quad\zeta_n=\frac{\alpha}{2\omega_n}+\frac{\beta\omega_n}{2}
```

| 材料 | ζ_target | τ₁/s | τ₂/s | τ₄/s |
|---|---|---|---|---|
| Steel | 0.015 | 0.218 | 0.028 | 0.001 |
| Acrylic | 0.060 | 0.174 | 0.031 | 0.006 |
| Satinwood | 0.040 | 0.256 | 0.022 | 0.008 |
| PVC | 0.070 | 0.196 | 0.017 | 0.006 |

## Slide 18 — 音色 2：基频能量占比 R₁(t) → "叮→嗡" ➕📐📊

定义基频模态在时刻 t 的能量占比。基频衰减最慢——其比例随时间单调上升。

```
R_1(t)=\frac{A_1^2 e^{-2t/\tau_1}}{\sum_k A_k^2 e^{-2t/\tau_k}}
```

敲击瞬间 (t~0.01s) 所有弯曲模态幅度可比→频带宽→清脆"叮"。t~0.2s 后高阶衰减殆尽 (τ₄~10⁻³s)→仅剩基频→纯音"嗡"。金属 (τ₁/τ₄≈200) 的过渡比聚合物 (τ₁/τ₄≈30) 更慢。

| 材料 | τ₁/s | τ₂/s | τ₄/s | τ₁/τ₄ |
|---|---|---|---|---|
| Steel | 0.218 | 0.028 | 0.001 | ~200 |
| Acrylic | 0.174 | 0.031 | 0.006 | ~30 |
| Satinwood | 0.256 | 0.022 | 0.008 | ~30 |
| PVC | 0.196 | 0.017 | 0.006 | ~30 |

📊 `fig_R1_vs_t.png` `fig_tau_decay.png`

**实验方法**：phyphox FFT 时间切片——每 0.05~0.1s 取一帧频谱，提取基频幅值与总幅值之比。受限于手机 FFT 时间分辨率 (Δt~0.05s 时 Δf~20Hz)，仅能获取 6 个离散帧。实验值与理论曲线在趋势上一致——基频占比单调上升。COMSOL 仿真提供完整的模态分解与连续 τₙ 曲线。

**噪声与去噪**：phyphox 频谱泄漏 (Hanning 窗旁瓣→邻频干扰 ±0.03)；房间混响 (低频驻波 ±2%)；环境噪声 (40~50dB 底噪→低 SNR 帧)。去噪：每帧 3 次敲击取中位数频谱；2s 环境谱减除；基频幅值从 3-pt 抛物线插值峰提取。

## Slide 19 — 模态分类：哪些模态辐射声 ➕📐📊

## Slide 20 — 响度 1：Hertz 接触 → 等效冲量 → SPL ➕📐📊

小球 (R~5mm) 撞击尺面属 Hertz 弹性接触。接触半径正比于载荷与球半径的立方根 (a~0.3mm)。

```
a=\left(\frac{3FR}{4E^*}\right)^{1/3},\quad E^*=\frac{E}{1-\nu^2}
```

接触刚度 ∝E^(2/3)，动量传递效率按 E^(1/3) 缩放——软材料获更少等效冲量。

```
\frac{J_{\rm eff}}{J_{\rm steel}}=\left(\frac{E_{\rm target}}{E_{\rm steel}}\right)^{1/3}
```

| 材料 | E/GPa | J_scale | J_eff/N·s |
|---|---|---|---|
| Steel | 200 | 1.000 | 0.040 |
| Acrylic | 3.2 | 0.255 | 0.010 |
| Satinwood | 2.0 | 0.218 | 0.009 |
| PVC | 3.0 | 0.250 | 0.010 |

声压与表面加速度成正比，加速度与冲量成正比。得 SPL 与冲量的对数关系。

```
{\rm SPL}=A+20\log_{10}J
```

📊 `fig_spl_vs_logJ.png`

**实验拟合**（写在 PPT 文本框，不在图上）：
SPL = 76.6 + 19.7·log₁₀(J)，R² = 0.829。理论斜率 20.0，偏差 −0.3 dB/dec

**噪声与去噪**：手机麦克风 ±2 dB；释放高度 ±5%；环境噪声 40~50 dB。去噪：每 J 值重复 5 次取中位数，剔除 1.5×IQR 离群值；测前录 2s 环境谱减除。

**冲量测量方法**：小球从 h₁ 自由下落→反弹至 h₂。碰撞系数 e=√(h₂/h₁)。J=m√(2gh₁)(1+e)。

## Slide 21 — 响度 2：方向性 SPL + 距离衰减 ➕📐📊

z-bending 宽面 (+z, 30mm) 辐射面积 0.006 m²，窄边 (±y, 2mm) 仅 0.0004 m²——面积比 15。

```
\Delta{\rm SPL}=20\log_{10}\left(\frac{30}{2}\right)=23.5\;{\rm dB}
```

```
{\rm SPL}(r)={\rm SPL}_0-20\log_{10}\left(\frac{r}{r_0}\right)
```

📊 `fig_spl_polar.png` `fig_spl_vs_logR.png`
