# Linux 服务器使用说明

本说明适用于在 Windows 电脑上通过 SSH 连接 Linux 服务器，使用 COMSOL Multiphysics 6.1 进行 Java 模型编译、求解和结果下载的全流程操作。建议先完整阅读一遍再动手。

---

## 1. 连接服务器

### 1.1 网络要求
服务器 IP 为 `<your-linux-server>`，属于私有地址，**必须通过校园网 VPN 连接**才能访问。若未连接 VPN，会直接 ping 不通、SSH 超时。
请先确认已成功连接学校/实验室提供的 VPN，再执行后续步骤。

> 若长期无法解决网络问题，请联系管理员申请跳板机（Jump Host）或开通你的 IP 到服务器的访问权限。

### 1.2 SSH 登录命令
在 Windows 的命令提示符（CMD）或 PowerShell 中执行：
```powershell
ssh -o ServerAliveInterval=30 user@<your-linux-server>
```
- `ServerAliveInterval=30` 每 30 秒发送心跳包，**防止长时间无操作时连接被防火墙断开**（重要！）。
- 首次登录需输入密码（`kdd` 的密码）。
- 成功后进入 Bash 环境，提示符类似 `user@SWS:~$`。

### 1.3 永久配置保活（推荐）
在 Windows 的 `C:\Users\你的用户名\.ssh\config` 文件中添加以下内容（没有则新建文本文件）：
```
Host <your-linux-server>
    ServerAliveInterval 30
    ServerAliveCountMax 3
    TCPKeepAlive yes
```
以后直接 `ssh user@<your-linux-server>` 即可自动保活。

## 2. 服务器环境设置

每次新登录后，都需要设置 Java 和 COMSOL 的环境变量（或写入 `.bashrc` 永久生效）。

### 2.1 临时设置（每次登录后执行）
```bash
export PATH=~/jdk-11.0.27+6/bin:/disk/home/zhangzhenlei/Comsol/comsol61/multiphysics/bin:$PATH
```
- JDK 11 位于用户目录 `~/jdk-11.0.27+6`，包含 `javac` 和 `java`。
- COMSOL 可执行文件路径已添加，可直接使用 `comsol` 命令。

### 2.2 永久设置（推荐）
将上面 `export` 命令追加到 `~/.bashrc` 末尾：
```bash
echo 'export PATH=~/jdk-11.0.27+6/bin:/disk/home/zhangzhenlei/Comsol/comsol61/multiphysics/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```
此后每次登录自动生效，无需手动设置。

### 2.3 验证环境
```bash
java -version          # 应显示 OpenJDK 11.0.27
javac -version         # 应显示 javac 11.0.27
comsol batch -version  # 应显示 COMSOL 6.1.0.252
```

## 3. 上传 Java 文件到服务器

在 **Windows 的 PowerShell 或 CMD** 中执行 `scp` 命令（不要混淆在 SSH 终端内执行）。

### 3.1 上传单个文件
```powershell
scp C:\你的本地路径\模型.java user@<your-linux-server>:~/comsol_work/
```

### 3.2 上传整个目录
```powershell
scp -r C:\你的本地项目文件夹\ user@<your-linux-server>:~/comsol_work/
```

> **注意**：目标目录 `~/comsol_work/` 需先在服务器上创建：
> `ssh user@<your-linux-server> "mkdir -p ~/comsol_work"`

---

## 4. 编译 Java 模型

COMSOL 自带 `comsol compile` 命令，可自动管理依赖 JAR 包，**无需手工指定 classpath**。

### 4.1 进入工作目录
```bash
cd ~/comsol_work
```

### 4.2 编译 Java 文件
```bash
comsol compile 你的模型.java
```
- 若编译成功，无任何输出，目录下生成 `.class` 文件。
- 若提示错误，按提示修改代码（常见问题见第 7 节）。

### 4.3 Java 代码注意事项
- 保存模型使用 **`model.save("路径")`**，而非 `ModelUtil.save()`（COMSOL 6.1 不提供该静态方法）。
- 保存方法可能抛出 `IOException`，`main` 方法需声明 `throws IOException`。
- **文件保存路径建议用 `/tmp/`**，因为某些安全策略会阻止在工作目录写文件（如 `~/comsol_work`）。示例：
  ```java
  model.save("/tmp/mymodel.mph");
  ```

## 5. 运行求解（批处理模式）

### 5.1 生成 .mph 文件（如果 Java 代码本身会保存）
直接运行编译后的 `.class` 文件：
```bash
comsol batch -inputfile 你的模型.class -outputfile /tmp/结果.mph
```
如果 Java 代码里已经调用 `model.save()` 保存了 mph，则 `-outputfile` 可省略或不冲突。

### 5.2 对已有 .mph 文件求解
```bash
comsol batch -inputfile /tmp/mymodel.mph -outputfile /tmp/mymodel_solved.mph -study std1
```
- `-study std1` 指定要运行的研究（通常为 `std1`，按实际研究名称填写）。
- 求解进度会实时输出到屏幕。

### 5.3 后台运行（推荐，防断线）
使用 `nohup` 将任务放入后台，并将输出写入日志：
```bash
nohup comsol batch -inputfile /tmp/mymodel.mph -outputfile /tmp/mymodel_solved.mph -study std1 > comsol.log 2>&1 &
```
- 任务启动后，可随时退出 SSH，求解不会中断。
- 查看进度：`tail -f comsol.log`（按 `Ctrl+C` 退出查看不影响求解）。

### 5.4 参数说明（常用）
| 参数 | 说明 |
|------|------|
| `-inputfile` | 输入文件（.mph 或 .class） |
| `-outputfile` | 输出文件 |
| `-study` | 要求解的研究名称 |
| `-batchlog <file>` | 将日志同时保存到指定文件 |
| `-pname / -plist` | 参数化扫描（参数名/参数值列表） |
| `-np` | 设置使用的 CPU 核心数，如 `-np 4` |

## 6. 下载结果到本地

在 **Windows 的 PowerShell 或 CMD** 中执行：

### 6.1 下载单个文件
```powershell
scp user@<your-linux-server>:/tmp/mymodel_solved.mph C:\你的本地结果路径\
```

### 6.2 下载整个目录
```powershell
scp -r user@<your-linux-server>:~/comsol_work/ C:\你的本地结果路径\
```

## 7. 常见问题与解决方法

| 问题 | 可能原因 | 解决方法 |
|------|---------|----------|
| `ssh: connect to host ... Connection timed out` | 网络不通，未连接 VPN | 连接学校 VPN；若问题依旧，联系管理员确认服务器 IP 及防火墙 |
| `Connection closed by ... port 22` | 账号权限或 Shell 受限 | 联系管理员检查账号是否允许 SSH 登录 |
| 登录后很快自动断开 (`client_loop: send disconnect`) | 防火墙空闲超时 | 使用 `-o ServerAliveInterval=30` 保活 |
| `comsol: command not found` | 环境变量未设置 | 执行 `export PATH=...`（见第 2 节） |
| `javac: command not found` | JDK 未安装或 PATH 错误 | 使用 `~/jdk-11.0.27+6/bin/javac` 或设置 PATH |
| 编译时 `ModelUtil.save()` 未定义 | API 变更，应使用 `model.save()` | 改为 `model.save("文件名.mph")` |
| 编译时 `Unhandled exception type IOException` | 未处理异常 | 在 `main` 方法加 `throws IOException` |
| 运行时安全策略禁止写文件 | 工作目录受 COMSOL 安全策略限制 | 将模型保存到 `/tmp/`，或添加 `-comsolinifile` 指定 ini 关闭限制 |
| COMSOL 求解许可证报错 | 许可证不可用 | 联系管理员确认许可证状态 |
| SCP 上传/下载失败 | 路径或权限问题 | 检查远程路径是否存在，确保有写权限；可使用 `scp -v` 查看调试信息 |

## 8. 快捷脚本示例（Windows Batch）

将以下内容保存为 `run_comsol.bat`，双击运行可自动完成上传、求解、下载（需根据实际文件名修改）。

```bat
@echo off
set SERVER=user@<your-linux-server>
set WORKDIR=~/comsol_work
set LOCAL_SRC=C:\Users\OMEN\model\MyModel.java
set LOCAL_RESULT=C:\Users\OMEN\results
set MPHNAME=mymodel.mph
set SOLVEDNAME=mymodel_solved.mph

REM 1. 上传 Java 文件
scp %LOCAL_SRC% %SERVER%:%WORKDIR%/

REM 2. 远程编译、生成 mph 并求解（后台运行）
ssh -o ServerAliveInterval=30 %SERVER% "export PATH=~/jdk-11.0.27+6/bin:/disk/home/zhangzhenlei/Comsol/comsol61/multiphysics/bin:$PATH && cd %WORKDIR% && comsol compile MyModel.java && comsol batch -inputfile MyModel.class -outputfile /tmp/%MPHNAME% && nohup comsol batch -inputfile /tmp/%MPHNAME% -outputfile /tmp/%SOLVEDNAME% -study std1 > comsol.log 2>&1 &"

echo Solution started in background. You can close this window.
pause
```
