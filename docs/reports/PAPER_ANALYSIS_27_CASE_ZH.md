## 1. 分析概述

基于 27 个 COMSOL 声场仿真 case 的高精度派生指标，对尺子振动声学特性进行系统分析。结论按可信度分为四层：

| 层级 | 含义 | 结论数 |
|---|---|---|
| **强结论 (strong)** | 数据一致性好、物理关系清晰、可定量验证 | 4 |
| **初步证据 (moderate)** | 趋势明显但受限于分辨率或样本量 | 3 |
| **暂不可结论 (preliminary)** | 数据基础不足，需 finer quality 确认 | 1 |
| **不适用 (N/A)** | 当前数据无法支持该分析 | 1 |

所有结论均基于 **coarse (0.10 s)** 时间窗口。图谱分析文件位于 `figures/paper_analysis/`，汇总数据位于 `tables/paper_analysis/`。

## 2. 强结论

### 2.1 主频与自由段长度的平方反比关系 f ∝ 1/L²

**图：** `pitch_vs_L_free.png`

钢材尺子 5 个自由段长度 (10–26 cm)：

| L_free (cm) | f_dom (Hz) | f × L² (Hz·cm²) |
|---|---|---|
| 10 | 161.5 | 16150 |
| 14 | 82.2 | 16111 |
| 18 | 49.7 | 16103 |
| 22 | 33.2 | 16069 |
| 26 | 23.8 | 16089 |

**f × L² = 16106 ± 28 Hz·cm²**，变异系数 0.17%。f ∝ 1/L² 被定量验证到极高的精度，是悬臂梁理论 f₁ ∝ (h/L²)√(E/ρ) 的有力仿真验证。

### 2.2 主频与厚度成正比 f ∝ h

**图：** `pitch_vs_h.png`

钢材尺子 5 个厚度 (1–5 mm)：

| h (mm) | f_dom (Hz) | f/h (Hz/mm) |
|---|---|---|
| 1 | 20.3 | 20.30 |
| 2 | 40.2 | 20.10 |
| 3 | 60.2 | 20.07 |
| 4 | 80.1 | 20.03 |
| 5 | 100.0 | 20.00 |

**f/h = 20.10 ± 0.11 Hz/mm**，R² > 0.999。f ∝ h 的线性关系被定量验证。截距近似为零，符合理论预期。

### 2.3 脉冲幅值主要增大响度，主频不变

**图：** `spl_vs_J.png`

钢材尺子 4 个脉冲幅值 (0.02–0.08 Ns)：

| J (Ns) | SPL (dB) | f_dom (Hz) |
|---|---|---|
| 0.02 | 83.0 | 40.22 |
| 0.04 | 88.9 | 40.23 |
| 0.06 | 92.5 | 40.24 |
| 0.08 | 95.0 | 40.23 |

**SPL 单调递增 +12.0 dB**，f_dom = 40.23 ± 0.01 Hz（相对变化 < 0.05%）。脉冲幅值在弹性范围内仅影响振动幅度（进而影响声压级），不改变系统特征频率。这是线性系统行为的直接体现。

### 2.4 材料刚度/密度比决定主频范围

**图：** `timbre_material_map.png`

5 种材料的主频覆盖 12–277 Hz 范围：

| 材料 | f_dom (Hz) | 推测的刚度/密度比趋势 |
|---|---|---|
| PVC | 12.1 | 最低 |
| 亚克力 | 13.5 | 相近 |
| 花梨木 (satinwood) | 32.1 | 中等 |
| 钢 (steel) | 40.1 | 较高 |
| 学府板 (xuefu_board) | 276.5 | 显著高 |

学府板的主频是钢的 6.9 倍，反映其极高的等效刚度/密度比。材料的定量声学特性对比见 `tables/paper_analysis/material_timbre_summary.csv`。

## 3. 初步证据

### 3.1 宽度对主频影响小，但宽梁时模态耦合退化

**图：** `mode_match_by_case.png`

| b (cm) | f_dom (Hz) | 最佳模态匹配误差 (%) |
|---|---|---|
| 1 | 40.0 | 0.05 |
| 2 | 40.1 | 0.06 |
| 3 | 40.2 | 0.08 |
| 4 | 40.3 | 4.83 |
| 5 | 40.4 | 5.20 |

**趋势：** b ≤ 3 cm 时模态匹配误差 < 0.1%，b ≥ 4 cm 时上升至约 5%。这表明**窄梁假设在宽度 ≥ 4 cm 时逐渐失效**，与理论预期一致。但 0.10 s 粗时间窗的频率分辨率有限，更精确的宽度阈值需要 medium/full 品质数据。

### 3.2 敲击位置影响激发模态和响度

**图：** `spl_vs_x0_ratio.png`

| x₀/L | SPL (dB) | f_dom (Hz) |
|---|---|---|
| 0.25 | 97.5 | 249.0 |
| 0.50 | 102.3 | 249.1 |
| 0.75 | 90.7 | 244.2 |

**趋势：** 中点敲击 (x₀/L = 0.50) 产生最高声压级 (102.3 dB)。三个位置均激发了约 **245–249 Hz 的高阶模态**而非 40 Hz 基频，表明偏端激励有效抑制了基频。但仅 3 个样本点，插值曲线仅供参考。

### 3.3 音色可由频谱质心 + 频谱平坦度量化

**图：** `timbre_material_map.png`（颜色 = SPL）

| 材料 | 频谱质心 (Hz) | 频谱平坦度 |
|---|---|---|
| 亚克力 | 73.6 | 0.0009 |
| PVC | 109.8 | 0.0012 |
| 花梨木 | 47.9 | 0.0008 |
| 钢 | 49.5 | 0.0014 |
| 学府板 | 237.6 | 0.0014 |

频谱质心反映了"亮暗"感知 (47.9–353.5 Hz)，频谱平坦度反映了"纯音/噪声"程度 (0.0008–0.0187)。各材料在主频-质心-平坦度空间中形成可区分的聚类，说明音色量化方法有效。但由于 coarse 分辨率，高频区域的能量分布可能不完全准确。

## 4. 暂不可结论

### 4.1 高频衰减趋势

当前所有 case 的 band_decay 指标标记为 `preliminary_coarse_time_window`。27/27 case 的 band_decay_metrics.csv 已生成，但 **0.10 s 时间窗不足以支撑可靠的衰减时间估计**。具体原因：

- STFT 的时间频率分辨率受限（0.020 s Hann 窗，0.005 s hop）
- 衰减时间可能超过时间窗长，导致截断误差
- 高频段 (1100–1700 Hz) 的信噪比因 coarse 网格降低

**建议：** 在 medium (0.5 s) 或 full (1.0 s) 品质数据上重新计算 band_decay_metrics。

---

## 5. 不适用

### 5.1 Q 因子估计

所有 27 个 case 的 `q_source = missing_tip`，`q_estimate = NaN`。原因是本批次仿真未输出 `tip_timeseries.csv`。结构探针 (structure_probe) 数据不能用于 Q 因子估计（非 tip 位置）。

**修复条件：** 需在 COMSOL Java 模板中增加 tip 位置 (自由端) 的时程输出，使用 medium 或 full 品质运行。

## 6. 模态声学耦合总览

**图：** `mode_match_by_case.png`

横虚线标记 2%、5%、10% 的匹配质量阈值：

- 全部 27 个 case 的 6 阶模态均被匹配
- 大多数 case 的最佳匹配误差 < 1%（绿色区域）
- b ≥ 4 cm 的 case 误差上升到 4–5%（黄色区域）
- 学府板 (xuefu_board) 误差最大 (5.96%)，可能与材料参数非均匀性有关
- 无 case 超过 10% 阈值（红色区域）

**结论：** 模态声学耦合匹配方法在 coarse 分辨率下表现良好，适合后续论文使用。

## 9. 局限性汇总

1. **全部结论基于 coarse (0.10 s) 时间窗**，频率分辨率约 10 Hz/bin
2. **FFT 使用 Hann 窗 + 4× 零填充**，峰值精炼使用抛物线插值
3. **频带衰减结论必须在 medium/full 品质数据上重算**，当前仅为初步
4. **Q 因子缺少 tip_timeseries.csv**，需修改 COMSOL 模板后重算
5. **模态匹配在高阶和宽带 case 上退化**，b ≥ 4 cm 时误差升至 ~5%
6. **材料参数未独立测量**，f_dom 差异的来源（刚度 vs 密度）无法分离
7. **所有 case 为 3D 声场模型**，未与实验数据交叉验证
