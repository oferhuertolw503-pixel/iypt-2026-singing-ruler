# 钢几何非线性 (gNL) 扫掠分析

> 日期: 2026-05-18 | 质量: fast (mesh=40, time_end=0.25s) | COMSOL 6.1  
> 每个 case 同时跑 gNL=on 和 gNL=off，5 case × 2 = 10 次仿真

---

## 1. 研究目的

在 unified（统一物理）包 baseline (L=20cm, h=2mm, J=0.04Ns) 下，钢的 probe 峰值仅 4.6mm，probe/L=2.3%，gNL 贡献 <2%。本扫掠通过系统性地改变 L、h、J 来加大振幅，量化 gNL 的起始阈值和增长规律。

## 3. gNL on vs off 比较

### 3.1 基频 (f₁)

| Case | gNL=on | gNL=off | 差异 |
|---|---|---|---|
| L20_h20_J004 | 41.22 Hz | 41.22 Hz | **0.00%** |
| L30_h20_J004 | 18.26 Hz | 18.26 Hz | **0.00%** |
| L30_h15_J004 | 13.70 Hz | 13.70 Hz | **0.00%** |
| L40_h20_J004 | 10.26 Hz | 10.26 Hz | **0.00%** |
| L20_h20_J016 | 41.22 Hz | 41.22 Hz | **0.00%** |

**发现**: f₁ 是线性特征值 — 来自 COMSOL Eigenfrequency Study，不经过 gNL 求解器。gNL 不改变特征频率。若要检测 gNL 引起的瞬时频率变化，需要从瞬态位移信号做 FFT 或 Hilbert-Huang 变换提取瞬时频率。

### 3.2 探针峰值 (Probe Peak)

| Case | gNL=on | gNL=off | 差异 | 物理意义 |
|---|---|---|---|---|
| L20_h20_J004 | 4.63 mm | 4.63 mm | **-0.1%** | 无效应 |
| L30_h20_J004 | 6.55 mm | 6.55 mm | **+0.0%** | 无效应 |
| L30_h15_J004 | 11.61 mm | 11.72 mm | **-0.9%** | 极微弱刚化 |
| L40_h20_J004 | 8.98 mm | 9.00 mm | **-0.2%** | 无效应 |
| L20_h20_J016 | 18.35 mm | 18.47 mm | **-0.7%** | 极微弱刚化 |

**发现**: 即使在最大振幅 case (w/h=9.2)，gNL 使峰值振幅仅降低 0.7-0.9%。膜应力刚化效应极弱，弯曲主导结构响应。

**理论解读**: 根据 gNL 梁理论，等效刚度 k_eff = k_linear · (1 + α·(w_max/h)²)。当 w/h=9.2 时，即使 α=1.5（自由端集中力），修正为 1 + 1.5×84 = 127×。但这仅适用于**静力学**大挠度。在本研究的**瞬态动力学**中，振幅在 0.25s 内衰减至初始的 ~50%，平均 w/h 远小于峰值，gNL 的平均效应被稀释。此外，钢的 E=200GPa 使弯曲刚度极高，就算 w/h=10，膜应力也仅占弯曲应力的 ~1-2%。

### 3.3 声压 (SPL)

| Case | gNL=on | gNL=off | 差异 |
|---|---|---|---|
| L20_h20_J004 | 86.7 dB | 86.5 dB | **+0.2 dB** |
| L30_h20_J004 | 82.5 dB | 81.9 dB | **+0.6 dB** |
| L30_h15_J004 | 89.6 dB | 89.3 dB | **+0.3 dB** |
| L40_h20_J004 | 89.9 dB | 89.7 dB | **+0.2 dB** |
| L20_h20_J016 | 98.0 dB | 98.6 dB | **-0.5 dB** |

**发现**: gNL 对所有 case 的 SPL 影响 <1 dB，低于仿真噪声水平。gNL 不改变声固耦合的能量传递效率。

### 3.4 模态衰减 (τ₁)

| Case | gNL=on | gNL=off | 差异 | R²_range |
|---|---|---|---|---|
| L20_h20_J004 | 0.176s | 0.193s | **-9.2%** | 0.77-0.83 |
| L30_h20_J004 | 0.214s | 0.204s | **+4.9%** | 0.89-0.89 |
| L30_h15_J004 | 0.039s | 0.039s | **-0.4%** | 0.76-0.76 |
| L40_h20_J004 | 0.077s | 0.077s | **-0.6%** | 0.97-0.97 |
| L20_h20_J016 | 0.164s | 0.189s | **-13.4%** | 0.83-0.76 |

**发现**: 最大的 gNL 效应出现在最大振幅 case (J=0.16, probe=18.4mm) — τ₁ 下降 13%。这意味着在最大振幅下，gNL 引入了额外的耗散机制（膜-弯耦合可能导致更多的内摩擦或向高阶模态的能量传递）。但其他 case 中此效应不显著。

## 4. 频率缩放 — Euler-Bernoulli 验证

所有 case 使用钢，E=200GPa, ρ=7850 kg/m³。

| Case | 实测 f₁ | EB 预测 | 误差 | 缩放律验证 |
|---|---|---|---|---|
| L20 (基准) | 41.22 | 40.8 | +1.1% | — |
| L30 | 18.26 | 41.22×(20/30)² = 18.32 | **0.3%** | ✓ 完美 |
| L40 | 10.26 | 41.22×(20/40)² = 10.31 | **0.5%** | ✓ 完美 |
| h=1.5mm | 13.70 | 18.26×√(1.5/2.0) = 15.82 | **预测偏差** | ✗ h 缩放偏离 |

## 5. 全面结论

### 5.1 gNL 效应量级

| 可观测量 | 最大 gNL 效应 | 发生条件 | 统计显著性 |
|---|---|---|---|
| f₁ | **0%** | — | 特征频率是线性量，不受 gNL 影响 |
| Probe peak | **0.9%** | h=1.5mm, probe=11.6mm | 边界显著 |
| SPL RMS | **0.6 dB** | L=30cm | 低于噪声水平 |
| τ₁ | **13%** | J=0.16, probe=18.4mm | **显著但不稳定** |
| 谱质心 | 不可靠 | — | 0.25s 窗口不足以可靠 FFT |

### 5.2 终极结论

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  在 probe/L ≤ 9.2% 和 w/h ≤ 9.2 的参数范围内，               │
│  钢 (E=200GPa) 的几何非线性对所有关键指标                     │
│  的修正 ≤ 2%。仅 τ₁ 在最大振幅下显示 ~13% 的衰减加速。        │
│                                                              │
│  gNL 在本项目的材料参数和几何范围内是次主导效应。              │
│  主导修正来自：(1)材料 Rayleigh 阻尼、(2)Hertz 冲量缩放、     │
│  (3)长时间窗口对衰减拟合的改善。                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 5.3 局限

1. **频率检测方法**: 当前 pipeline 从特征值求解器读取 f₁，不受 gNL 影响。要检测 gNL 引起的瞬态频移，需要从位移时序信号做瞬时频率分析（不再做）。
2. **fast 质量**: 0.25s 窗口和 mesh=40 适合于 gNL 比较（看相对差异），但绝对声学指标（谱质心、平坦度）不可靠。这些已在 unified 质量（1.0s 窗口）中给出。
3. **最大振幅受限**: h=1mm 的 case 因 DOFs 爆炸未能运行，probe/L 的上界为 9.2%。更极端情况可能需要 Shell 单元。
4. **FEM 收敛性**: fast 质量 mesh=40 在 gNL 区域的可收敛性未验证，但 on/off 比较在相同网格下可信。
